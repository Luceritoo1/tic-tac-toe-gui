# 🎮 Tic Tac Toe GUI en Python

Proyecto desarrollado como práctica integradora de **Git y GitHub** aplicando un flujo
de trabajo profesional con ramas, commits y Pull Requests.

---

## 📌 Descripción

Este proyecto implementa el juego **Tic Tac Toe (Tres en Raya)** con una interfaz gráfica
usando **Python** y la librería **Tkinter**.  
El desarrollo se realizó utilizando la metodología **Feature Branching**.

---

## 🛠️ Tecnologías utilizadas

- Python 3.x
- Tkinter
- Git
- GitHub
